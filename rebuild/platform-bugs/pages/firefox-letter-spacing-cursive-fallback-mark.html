letter-spacing opens a gap inside a joined Arabic word after a mark that a fallback font draws

Two joined Arabic words in 40px Geeza Pro, each at 0 and at 8px of letter spacing. The first word's mark is U+064E ARABIC FATHA, which Geeza Pro has. The second word's mark is U+0301 COMBINING ACUTE ACCENT, which Geeza Pro lacks, so another font draws it. Letter spacing isn't applied between the letters of a cursive script, so neither word should grow. Which font draws a mark shouldn't matter.

Two equal strings wrap differently under word-break: keep-all

Both red boxes are 100px wide, 16px Menlo, word-break: keep-all, and hold the ASCII text abcdefgh,ijklmnopqr. The first string is a plain literal. The second is .slice(1) of a literal that starts with a Chinese character, so the engine keeps it in UTF-16 storage. JavaScript can't tell them apart (a === b). They should lay out the same: one overflowing line, because UAX #14 has no break after a comma before a letter (LB29).

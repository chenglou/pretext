Tab stops are measured with the font of the inline box that holds the tab, not the block's font

Both lines are 16px Times New Roman blocks with white-space: pre; tab-size: 8, holding a tab and x. In the second line the tab is inside a <span> in 16px Menlo. CSS Text defines a numeric tab-size as a multiple of the space advance of the tab's nearest block container ancestor, so the x should start at 8 Times New Roman spaces (32px) in both lines.

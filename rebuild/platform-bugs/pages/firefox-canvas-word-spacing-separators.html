Canvas wordSpacing spaces U+3000 and skips U+00A0; CSS word-spacing does the opposite

a b with three different spaces, 16px Georgia, 10px of word spacing. CSS Text names U+0020 and U+00A0 as word separators and says fixed-width spaces such as U+3000 aren't. The canvas text preparation algorithm applies wordSpacing as the CSS property, so a canvas should add what the DOM adds: 10px for U+0020 and U+00A0, nothing for U+3000.

Canvas text in system-ui ignores automatic optical sizing, and a canvas element and an OffscreenCanvas differ

A pangram in system-ui (SF Pro, which has an opsz axis) at four sizes: a DOM span, the same span with font-optical-sizing: none, an OffscreenCanvas and a <canvas> element. font-optical-sizing is auto by default and the canvas font shorthand resets it to that, so both canvases should measure what the first DOM column measures.

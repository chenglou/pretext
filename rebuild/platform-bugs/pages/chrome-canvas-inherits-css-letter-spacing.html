A 2D canvas takes letter-spacing and word-spacing from the canvas element's CSS

Both canvases set ctx.font = '40px Arial' and nothing else, and ctx.letterSpacing reads 0px on both. The second canvas sits inside a <div> with letter-spacing: 5px; word-spacing: 7px. The canvas text preparation algorithm takes letter and word spacing from the context attributes, so both canvases should measure and draw ab cd the same.

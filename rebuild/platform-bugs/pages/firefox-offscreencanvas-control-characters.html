An OffscreenCanvas and a canvas outside the document measure invisible characters that a canvas in the document and DOM text skip

18px Arial. A U+200E V holds a left-to-right mark, and a U+0001 b holds a C0 control. A <canvas> element in the document measures both like AV and ab, as DOM text does. A canvas element outside the document and an OffscreenCanvas on the same thread, with the same font and the same string, should measure the same as the one in the document.

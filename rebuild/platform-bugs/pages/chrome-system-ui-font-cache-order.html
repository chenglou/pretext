system-ui DOM text changes width after a canvas measured system-ui at that size x devicePixelRatio

Needs devicePixelRatio above 1 (a Retina display, or page zoom) and a fresh renderer: open the page in a new tab of a new window, and don't reload. Two spans hold Hello world in system-ui. The 13px span is laid out before any canvas touched system-ui. Before the 15px span is laid out, a canvas measures system-ui at 15px x devicePixelRatio. A canvas measurement should not change how DOM text lays out, so both spans should be as wide as a canvas measures the same text at the span's CSS size (within a layout unit).

Pretext

Pure TypeScript library for multiline text measurement & layout.

Fast, accurate & supports all the languages you didn't even know about.

npm install @chenglou/pretext

Demos

AccordionClassic expand & collapse of sections, animated, with no FLIP technique, DOM measurement or reflow. BubblesMultiline bubbles shrinkwrapped to their text, keeping the same line count while wasting less width. Dynamic LayoutA fixed-height editorial spread with obstacle-aware title routing and continuous flow. Variable Typographic ASCIIParticle-driven ASCII art comparing proportional measured glyphs against a monospace version. Editorial EngineAnimated orbs, live text reflow, pull quotes, and multi-column flow with no DOM text measurement. Justification ComparisonCSS vs. greedy vs. TeX’s famous Knuth-Plass layout, side by side, to reveal rivers and other spacing tradeoffs. Rich TextRich inline text, code spans, links, chips, a custom emoji and an image laid out together, with pills and images staying whole while text keeps wrapping naturally. Markdown ChatGiant stress test: a virtualized rich-text chat of 10,000 Markdown messages, scrolling & resizing at 120fps. EllipsisText clamped to a number of lines, an ellipsis in the middle of a path, and a “… more” link, all cut before anything is painted. MasonryPure JS masonry layout with occlusion aka virtualization, unlocked simply by Pretext’s height measurement.
